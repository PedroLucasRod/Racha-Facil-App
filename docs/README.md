# ⚽ Racha Fácil

Sistema web desenvolvido para facilitar a organização de rachas de futebol amador.

O projeto foi criado como atividade extensionista do curso de Análise e Desenvolvimento de Sistemas da UNIASSELVI, em parceria com a Tree Company, responsável pela organização do grupo de futebol.

---

## Objetivo

O Racha Fácil substitui a organização feita atualmente por WhatsApp, centralizando todas as informações do evento em um único sistema.

Entre suas principais funcionalidades estão:

- Cadastro de jogadores
- Confirmação de presença
- Lista de espera automática
- Histórico das partidas
